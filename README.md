# Emerald Frost (demo)

A theme published for [Theme Studio](https://github.com/agentic-tool-labs/herdr-theme-studio), the
[Herdr](https://herdr.dev) app's theme editor: navy glass over five glows of cyan, teal and emerald.
It exists to test importing from GitHub.

In Theme Studio, open **Import** and click **Browse themes** (this repo carries the topic
`herdr-mod-theme-studio`), or paste this repo's link into the GitHub field. It brings its whole
look: colors, glass, fonts, cursor and agents list. See Theme Studio's README, "Publishing a theme",
to publish your own.
